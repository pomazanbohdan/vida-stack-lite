# Паралель незалежні задачі
Згрупуй роботу за незалежними предметними межами.
Перевір, що одна задача не змінює вхід іншої.
Виявляй спільні файли та спільний мінливий стан.
Залиш залежні задачі послідовними.
Не паралель дослідження, якому потрібен спільний повний контекст.
Признач одного власника кожній спільній ділянці роботи.
Обмеж кожну задачу чітким обсягом і результатом.
Передай виконавцю всі вимоги, потрібні для автономної роботи.
Назви заборонені зміни та залежності явно.
Вкажи формат звіту, потрібний для інтеграції.
Запускай незалежні задачі одночасно лише за відсутності конфліктів.
Не запускай паралельно двох виконавців на одну й ту саму задачу.
Не створюй більше паралельних потоків, ніж можна перевірити.
Отримай результат кожного власника перед його приєднанням.
Перевір диф кожного незалежного результату.
Усунь конфлікти перед спільною перевіркою.
Перевір, що задачі не дублюють одна одну.
Запусти повний набір перевірок після інтеграції результатів.
Повідом окремо про невиконані чи заблоковані задачі.
Не вважай паралельний запуск доказом успішного завершення.
