# Identify real competitive alternatives

Identify all alternatives best customers would use if the product disappeared, including direct competitors, manual processes, spreadsheets, hiring, and doing nothing. Interview 15–20 happy customers about what they switched from; group similar alternatives and account for segment differences. Base the alternatives on actual research, not assumptions.

# Define the narrowest best-fit customers

Define the narrowest current customer group that cares most about the value delivered, using characteristics identifiable before contact. Work backward from successful customers; do not use “everyone” or assume best-fit means the largest market. Include negative-fit criteria. Focus the definition without denigrating other segments.

# Avoid common positioning mistakes

Avoid positioning for everyone, confusing positioning with messaging, listing features instead of customer value, copying competitors, changing positioning too frequently, creating a new category prematurely, and ignoring alternatives. Tighten best-fit focus, do positioning before messaging, use value mapping and owned attributes, commit for 6–12 months while allowing more frequent messaging changes, create a new category only with traction and resources, and interview happy customers about prior alternatives.

# Choose the market frame that clarifies value

Choose the market frame that makes unique value clearest: compete head-to-head, create a subcategory, or create a new category only when existing categories cannot describe the product. Weigh inherited assumptions against the education cost, test whether prospects understand the category within 30 seconds, and do not create a category merely to avoid competition.

# Set positioning context deliberately

Positioning sets the context in which customers compare a product: category, alternatives, and perceived value. Choose context that makes the product's genuine strengths clear; positioning is distinct from messaging.
