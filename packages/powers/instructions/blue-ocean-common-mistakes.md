# Avoid common blue-ocean mistakes

Avoid competing on the same factors, differentiation without cost focus, incrementalism, imitation and ignoring adoption. Use ERRC to create a divergent curve and pursue both cost and value changes, use the six paths to find alternatives, and plan for adoption early.
