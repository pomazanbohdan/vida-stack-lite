# Make useful information easy to pass along

Make useful information easy to pass along; practical value spreads as a favor that can save others time, money, or effort. Apply the source's Prospect Theory framing and Rule of 100 (percentage discounts under $100; dollar amounts over $100), recognize that niche content can be forwarded to the person who needs it, and package knowledge in lists, how-tos, and tips. Value must be genuine; do not use inflated original prices or clickbait life hacks.
