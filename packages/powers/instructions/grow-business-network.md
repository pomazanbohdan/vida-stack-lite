# Turn customers into a network

Phase 7 turns referrals into a self-reinforcing acquisition loop. Network effects begin as liability; saturate one tiny complete network at a time, not broadly. Define the atomic network as the smallest self-sustaining unit (such as a firm or city), over-deliver until dense, then replicate with a playbook. Build first for the hard side: the minority doing disproportionate work and hardest to retain. A tipping playbook may use invite-only mechanics and two-sided referrals importing each user through an existing relationship. Define network, hard side and retention reason, and real incentives for both sides; extend MARKETING.md with mechanics. Done includes density, not signup, metrics named for Phase 8.
