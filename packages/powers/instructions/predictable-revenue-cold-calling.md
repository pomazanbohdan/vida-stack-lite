# Use Cold Calling 2.0 instead of cold calling

Use Cold Calling 2.0 instead of traditional cold calling, which source says has 1–3% connection rate, gatekeepers, brand damage, and no scalability. Sequence: build list, send mass email, get referral, call referral, qualify.
