# Apply the four ERRC actions

Use the four ERRC questions: eliminate factors adding no buyer value and reduce factors below industry standard to lower cost; raise factors above standard and create new factors to increase value and attract non-customers. Test assumptions before cutting, especially for safety or accessibility factors buyers value.
