# Складай виконуваний план реалізації
Зафіксуй ціль зміни одним реченням.
Вкажи вимоги, межі та критерії приймання.
Назви файли й компоненти, які мають змінитися.
Відділи передумови від задач, що їх споживають.
Визнач інтерфейси між залежними задачами.
Розбий роботу на найменші самостійні результати.
Розташуй задачі в порядку їхніх залежностей.
Для кожної задачі назви конкретний файл або власника.
Опиши перевірний результат кожної задачі.
Додай перевірку до задачі, яка створює її предмет.
Задай точні імена тестів для поведінкових вимог.
Задай команди та очікувані результати для перевірок.
Познач вплив на документи, розгортання й відкат.
Не додавай кроків, які не змінюють результат або доказ.
Не повторюй у плані нормативний текст специфікації.
Не залишай невизначені кроки на кшталт «обробити крайові випадки».
Перевір, що всі вимоги мають задачу та критерій.
Перевір узгодженість імен, полів та інтерфейсів між задачами.
Скороти план, якщо його деталі повторюють саму реалізацію.
Передай план на погодження, коли рішення впливає на обсяг чи поведінку.
