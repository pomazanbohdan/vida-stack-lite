# Run the ten-step offer process

For an offer built from scratch, follow the listed sequence: (1) identify and score a starving crowd on pain, purchasing power, targetability, and growth; (2) define the single most desirable Dream Outcome in the customer's words; (3) list every problem, fear, objection, and friction; (4) create a solution and delivery vehicle for each obstacle; (5) remove low-value/high-cost solutions and keep high-value/low-cost ones; (6) price at 10–20% of the Dream Outcome's value (a 10:1 to 5:1 ratio); (7) create one named bonus per remaining objection with a defensible dollar value; (8) choose a model- and risk-appropriate guarantee, name it, and make it bold; (9) use genuine limits and real deadlines for scarcity and urgency; and (10) name with MAGIC using avatar, goal, timeframe, and container, testing 3–5 variations.
