# Use the nine-phase journey map

Use the phase map to route each question to its named skill and artifact. Four phases write MARKETING.md; OFFER.md, STRATEGY.md, METRICS.md, and CUSTOMER.md are extended, reusing prior journey files without overwriting them. GROW-BUSINESS-PLAN.md is private to this journey and is its cross-session resume point.
