# Define the narrowest best-fit customers

Define the narrowest current customer group that cares most about the value delivered, using characteristics identifiable before contact. Work backward from successful customers; do not use “everyone” or assume best-fit means the largest market. Include negative-fit criteria. Focus the definition without denigrating other segments.
