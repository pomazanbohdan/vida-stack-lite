# Build the accountability chart

Use an Accountability Chart to define organizational structure and ownership, not merely an org chart; it includes Visionary, Integrator, Sales/Marketing, Operations, and Finance roles. The Visionary handles big ideas, culture, key relationships, and creative problem solving; the Integrator runs day-to-day operations, manages the team, and executes the vision. Assign one person per seat because shared accountability is no accountability. Assess every person with the People Analyzer: rate core-value fit as +, +/-, or -; all values must be +, one +/- calls for a conversation, and any - means the person is wrong for the role. Assess GWC (Gets it, Wants it, Capacity—mental, physical, emotional); all three must be yes. Right person/right seat: keep and invest; right person/wrong seat: move; wrong person/right seat: coach or exit; wrong person/wrong seat: exit immediately. Consult the people reference for templates and scoring.
