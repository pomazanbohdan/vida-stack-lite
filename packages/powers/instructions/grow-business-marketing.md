# Install the marketing operating system

Phase 1 maps marketing across a 3x3 Before (target market, message, media), During (capture leads, nurture, convert), and After (deliver experience, increase lifetime value, orchestrate referrals) grid. Score completeness and specificity of all nine squares 0-10, identify the weakest and three fixes, and run the PVP Index (Personal fulfillment, Value to market, Profitability) across candidate segments to choose a niche and write its avatar. Ask the user to choose the PVP niche, weakest square, and one named persona, not everyone. Create MARKETING.md with target market/avatar, the grid and channels; update tracker. Done only when grid is filled/scored, niche/avatar recorded, and user has chosen niche and square.
