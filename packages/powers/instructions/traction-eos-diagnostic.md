# Run the EOS diagnostic

Use the six diagnostic questions to identify gaps and take the paired action: if leadership does not agree on vision, complete the V/TO together; if people are not in the right seats, run People Analyzer on all seats; if data is not managed weekly, build a weekly scorecard; if issues are not solved permanently, use IDS in Level 10s; if core processes are not documented, document the top five; if 90-day priorities are not set and tracked, set quarterly rocks.
