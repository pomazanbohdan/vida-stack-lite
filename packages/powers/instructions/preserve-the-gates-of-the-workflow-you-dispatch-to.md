# Preserve the gates of the workflow you dispatch to
Execute end-to-end.
Preserve all workflow gates (phase discovery, per-phase execution, blocker handling, progress display).
Preserve all workflow gates (wave execution, checkpoint handling, verification, state updates, routing).
Load and execute the appropriate workflow end-to-end based on the routing table above.
Preserve all validation gates from the target workflow.
Preserve all workflow gates from the target workflow (directory structure, duplicate detection, commits, etc.).
