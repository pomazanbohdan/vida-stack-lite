# Build the accountability chart

Use an Accountability Chart to define organizational structure and ownership, not merely an org chart; it includes Visionary, Integrator, Sales/Marketing, Operations, and Finance roles. The Visionary handles big ideas, culture, key relationships, and creative problem solving; the Integrator runs day-to-day operations, manages the team, and executes the vision. Assign one person per seat because shared accountability is no accountability. Assess every person with the People Analyzer: rate core-value fit as +, +/-, or -; all values must be +, one +/- calls for a conversation, and any - means the person is wrong for the role. Assess GWC (Gets it, Wants it, Capacity—mental, physical, emotional); all three must be yes. Right person/right seat: keep and invest; right person/wrong seat: move; wrong person/right seat: coach or exit; wrong person/wrong seat: exit immediately. Consult the people reference for templates and scoring.

# Avoid the listed EOS mistakes

Avoid skipping Level 10 meetings: protect the weekly rhythm and never cancel. Avoid operating without a scorecard: choose 5-15 weekly numbers. Address wrong-person decisions with the People Analyzer and make difficult calls. Share the V/TO with the entire company so the team knows the vision. For rock-specific mistakes (too many, too vague, business-as-usual, or mid-quarter changes), consult references/rocks.md.

# Run the EOS diagnostic

Use the six diagnostic questions to identify gaps and take the paired action: if leadership does not agree on vision, complete the V/TO together; if people are not in the right seats, run People Analyzer on all seats; if data is not managed weekly, build a weekly scorecard; if issues are not solved permanently, use IDS in Level 10s; if core processes are not documented, document the top five; if 90-day priorities are not set and tracked, set quarterly rocks.

# Resolve issues with IDS

Use IDS (Identify, Discuss, Solve) to resolve issues: identify root cause by asking why until it is reached and state the issue in one sentence; discuss with input from everyone (not equal time), stop tangents, and address one issue at a time in a 5-15 minute time box; solve by deciding, assigning who/what/when actions, and moving on. Apply IDS to problems, ideas (decide yes/no/later), and obstacles (remove or escalate). Anyone may add issues; prioritize the most important first, and carry unsolved issues forward. Avoid symptom-only discussion, repeating the same issue weekly, and ending without clear actions. Consult the issues reference when facilitating.

# Install EOS in the staged sequence

A typical full EOS implementation takes two years. The sequence is Focus Day on day 1 (8 hours) for the accountability chart, rocks, scorecard, and Level 10; Vision Building Day 1 in month 1 for core values, core focus, and 10-year target; Vision Building Day 2 in month 2 for marketing strategy, 3-year, 1-year, and rocks; quarterly sessions every 90 days to review and set rocks and address major issues; and annual planning yearly for full V/TO review, 1-year plan, and Q1 rocks. Self-implementation is free and slower; a certified EOS Implementer is faster and expensive. Consult references/implementation.md for phase sequencing and the self-versus-Implementer decision, and references/case-studies.md for real-company sequencing examples.
