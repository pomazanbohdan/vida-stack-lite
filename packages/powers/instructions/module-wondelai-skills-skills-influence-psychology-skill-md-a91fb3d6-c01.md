# Build on freely chosen commitments

Use commitment and consistency by starting with small commitments and building toward larger ones; public, written, and active commitments are stronger. Every commitment must be freely chosen and easily reversible, with no trick opt-ins or defaults users cannot undo.

# Avoid common influence mistakes

Check each mistake against its correction: fake social proof -> use real data or do not use it; overuse of scarcity -> reserve it for genuine urgency; inconsistent authority -> do not claim expertise you lack; forced reciprocity -> give without an immediate ask; generic unity -> define a specific shared identity. State the correction for each mistake rather than referring to an unlisted list.

# Run the influence ethics diagnostic

Answer each question and apply its action: Which principles am I using? If none, design for influence explicitly. Am I combining principles? If not, layer multiple principles where truthful. Is the claim truthful? If not, remove or replace it. Does it help the user? If not, realign it with the user's goal. Would it still work if the user knew the strategy? If not, replace it with a transparent version. Can users easily reverse the decision? If not, add clear opt-outs. Is it safe for vulnerable users? If not, apply the safeguards or exclude them. Report each failed check and its correction.
