# Avoid common influence mistakes

Check each mistake against its correction: fake social proof -> use real data or do not use it; overuse of scarcity -> reserve it for genuine urgency; inconsistent authority -> do not claim expertise you lack; forced reciprocity -> give without an immediate ask; generic unity -> define a specific shared identity. State the correction for each mistake rather than referring to an unlisted list.
