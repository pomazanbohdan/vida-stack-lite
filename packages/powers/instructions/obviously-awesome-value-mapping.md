# Map attributes to customer value

For each unique attribute, repeatedly ask “So what?” until reaching customer-valued outcomes, express value in customer language, support themes with evidence, and group related values. The core concept says two or three themes, while the Key insights say most products support 2–4; retain this source conflict unresolved.
