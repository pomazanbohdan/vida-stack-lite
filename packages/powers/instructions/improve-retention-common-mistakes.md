# Avoid the listed retention mistakes

Avoid relying on motivation for retention, ignoring the weakest Ability Chain link, prompting below the Action Line, skipping celebration in onboarding, making the first action too ambitious, or copying other products without diagnosing B=MAP. Apply the corresponding fixes: make behavior tiny enough for motivation dips, audit all six factors and fix the scarcest, use event-based triggers only when motivation and ability suffice, add success states/micro-celebrations after key actions, shrink to one-field/one-action Starter Steps, and diagnose users' motivation, ability, and prompt context first.
