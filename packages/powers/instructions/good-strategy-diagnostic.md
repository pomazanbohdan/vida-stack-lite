# Run the strategy diagnostic

Apply all eight diagnostic questions: named challenge, choiceful guiding policy, coordinated resourced actions, competitor-specific fit, proximate first objective, exploited leverage or asymmetry, explicit no-list, and prior attempt to disprove the strategy. Follow each stated repair when an answer is no.
