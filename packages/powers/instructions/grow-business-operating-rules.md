# Apply the operating rules

On resumption, first read the tracker and all mapped artifacts; summarize state in 3-5 lines and ask for an entry phase; never restart a tracked journey. On first run, perform intake, create a tracker with each phase status pending, in-progress, awaiting-evidence, done, deferred with reason, or skipped with reason, and get confirmation of the phase plan. At phase entry explain purpose, decision, artifact, and rough effort; offer proceed, skip, or defer, except GATE phases may be deferred but never skipped; mark in-progress on proceed. Load and use the named skill; if unavailable, offer its install command and, if declined, use the Brief minimum method and state the mode. Ask every listed decision question with concrete options and a recommendation; record the choice. Present draft artifact for sign-off before writing; on approval create or extend docs, preserve existing content, update tracker status, decisions, and next actions, and mark done. Read before writing; create only missing files, otherwise extend; recommendations are checkboxes or table rows with owner and priority. First-created docs use the full artifact-template skeleton. Every scarcity claim, testimonial, and guarantee must be true; referral incentives reward real value delivered. Replace tactics requiring invented evidence with tactics using available evidence.
