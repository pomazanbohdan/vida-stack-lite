# Avoid common positioning mistakes

Avoid positioning for everyone, confusing positioning with messaging, listing features instead of customer value, copying competitors, changing positioning too frequently, creating a new category prematurely, and ignoring alternatives. Tighten best-fit focus, do positioning before messaging, use value mapping and owned attributes, commit for 6–12 months while allowing more frequent messaging changes, create a new category only with traction and resources, and interview happy customers about prior alternatives.
