# Point everything at one metric

Phase 8 selects one metric indicating whether the riskiest business activity works and gates experiments. Use comparative ratios/rates that change behavior; stop measuring metrics that change no decision, and treat cumulative rising totals as vanity signals. Derive OMTM from business model and stage (Empathy, Stickiness, Virality, Revenue, Scale); SaaS examples include churn, MRR, LTV:CAC and time-to-value. Pair OMTM with a counter-metric to prevent gaming, and commit to a target, date and response if missed. Segment and cohort metrics because blended averages hide truth. Record stage, OMTM, counter-metric, line in the sand, KPI definitions, baselines/targets, funnel and cohort notes; flag vanity metrics.

# Hold price in high-stakes conversations

Phase 9 holds price in high-stakes conversations through empathy and being understood, not logic or compromise. Never split the difference; no deal is preferable to a bad deal because pressured discounts train future customers to ask. Name concerns with tactical empathy/labels, use calibrated questions to make the counterpart solve the problem, preempt objections with an accusation audit, and use Ackerman decreasing increments to precise non-round numbers, closing with a non-monetary concession. Prepare a specific conversation, accusation audit, five calibrated questions, target, decreasing increments, walk-away, non-monetary concession and Black-Swan hypotheses. Record a reusable playbook; done when next negotiation and decisions are prepared.

# Turn customers into a network

Phase 7 turns referrals into a self-reinforcing acquisition loop. Network effects begin as liability; saturate one tiny complete network at a time, not broadly. Define the atomic network as the smallest self-sustaining unit (such as a firm or city), over-deliver until dense, then replicate with a playbook. Build first for the hard side: the minority doing disproportionate work and hardest to retain. A tipping playbook may use invite-only mechanics and two-sided referrals importing each user through an existing relationship. Define network, hard side and retention reason, and real incentives for both sides; extend MARKETING.md with mechanics. Done includes density, not signup, metrics named for Phase 8.

# Make the offer impossible to refuse

Phase 2 constructs a Grand Slam Offer before traffic. Apply Value = (Dream Outcome x Perceived Likelihood) / (Time Delay x Effort and Sacrifice), increasing the numerator and reducing the denominator. Combine core product, named objection-killing bonuses, risk-reversing guarantee and ethical real scarcity until the stack dwarfs price; name it with MAGIC (Magnetic reason, Avatar, Goal, time Indicator, Container). Premium pricing is intended to attract committed customers who churn less. Ask whether 'too expensive' reflects price or value construction, whether to raise price/add done-for-you bonus or hold, and which three bonuses ship. Create/extend OFFER.md with offer stack (honest value and objection killed) and price metric. Done only with scored offer, named bonuses, guarantee, real scarcity, MAGIC name and recorded pricing decision.

# Apply the operating rules

On resumption, first read the tracker and all mapped artifacts; summarize state in 3-5 lines and ask for an entry phase; never restart a tracked journey. On first run, perform intake, create a tracker with each phase status pending, in-progress, awaiting-evidence, done, deferred with reason, or skipped with reason, and get confirmation of the phase plan. At phase entry explain purpose, decision, artifact, and rough effort; offer proceed, skip, or defer, except GATE phases may be deferred but never skipped; mark in-progress on proceed. Load and use the named skill; if unavailable, offer its install command and, if declined, use the Brief minimum method and state the mode. Ask every listed decision question with concrete options and a recommendation; record the choice. Present draft artifact for sign-off before writing; on approval create or extend docs, preserve existing content, update tracker status, decisions, and next actions, and mark done. Read before writing; create only missing files, otherwise extend; recommendations are checkboxes or table rows with owner and priority. First-created docs use the full artifact-template skeleton. Every scarcity claim, testimonial, and guarantee must be true; referral incentives reward real value delivered. Replace tactics requiring invented evidence with tactics using available evidence.

# Manufacture pipeline with outbound

Phase 3 builds a controllable outbound pipeline. Use Seeds (referrals: highest conversion, slow to build), Nets (inbound: medium), and Spears (outbound: predictable, controllable volume); most underinvest in Spears. Specialize SDR prospecting, AE closing, and CSM retention; never combine prospecting and closing in one person. Cold Calling 2.0 emails above the decision-maker for a referral in, without pitching; cited response is 9-15% versus 1-3%. Qualify with ANUM (Authority, Need, Urgency, Money) and calculate pipeline backward from revenue goal. Ask for backward email/SDR math, four-touch sequence, ANUM handoff, goal/hiring/role and channel-mix decisions. Extend MARKETING.md with process and math; done only when math, sequence, qualification/handoff and decisions are recorded.

# Build persuasion into every surface

Phase 5 improves conversion on existing-traffic surfaces (pricing page, testimonials, checkout) without more acquisition spend. Audit Reciprocity, Commitment and Consistency, Social Proof, Authority, Liking, Scarcity and Unity. Prefer exact numbers to vague claims; negative social proof backfires; admitting weakness can raise authority; newly scarce framing is stronger than always-scarce. Persuasion helps people see value they would appreciate; manipulation works against their interests. Audit presence/misses, score, rewrite weak spots and ethics-check every tactic. Replace any tactic failing ethics review with one based on evidence available; verify all scarcity and proof claims are real. Extend OFFER.md with audit and concrete testimonials placed where objections peak; done when scored audit, rewritten proof and verified true claims are recorded.
