# Name the offer with MAGIC

Name an offer so that it communicates its audience, outcome, timeframe, and format clearly and briefly. MAGIC comprises Magnetic reason why (hook, event, season, or trend), Avatar, Goal (concrete Dream Outcome), time Indication, and Container word (such as challenge, blueprint, accelerator, bootcamp, system, formula, or masterclass). Use only elements that aid clarity and test 3–5 names. A name may be aspirational but must never deceptively promise an outcome customers do not actually reach.
