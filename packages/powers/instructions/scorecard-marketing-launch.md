# Run the launch checklist

Before launch, define the ideal customer and desired outcome; choose one of five hook types; write 2–7 methodology-based scoring categories and 10–40 questions with point values; set up three tiers with dynamic content; write a landing page with Clarity, Credibility, and Connection; configure lead-form fields; automate results email; create tier-specific follow-up; and test with 5–10 people.
