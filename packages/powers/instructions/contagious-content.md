# Match STEPPS drivers to content type

Select STEPPS drivers by content type as suggested in the table: Social Currency with Stories for thought leadership, Practical Value with Triggers for how-to guides, Emotion with Stories for brand films, and Practical Value with Public for interactive tools. The table gives examples, not exclusive pairings.
