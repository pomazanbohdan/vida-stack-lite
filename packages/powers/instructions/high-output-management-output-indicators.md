# Measure output indicators, not activity

Measure shipped output that survives, not activity such as code lines, hours or tickets touched. Pair every quantity indicator, including administrative throughput, with a quality counterpart so neither can be optimized at the other's expense. Favor leading indicators that warn early enough to act; compare trend indicators with the team's history and forecast. Re-forecast the same horizon each period in a stagger chart; reading down a column reveals honest, optimistic or sandbagged forecasts. Indicators measure work, not workers; surveillance encourages optimizing numbers over output.
