# Визнач масштаб і не починай без погодження
Налаштування користувача вирішує, яка з двох політик погодження активна: ця чи `proceed-without-waiting-for-confirmation`.
Якщо активною обрано `proceed-without-waiting-for-confirmation`, виконуй її замість цієї інструкції й не вигадуй третьої поведінки.
Визнач, це швидка задача, мала зміна чи проєкт із письмовим дизайном.
Назви масштаб власнику простими словами.
Дай власнику змогу змінити масштаб.
Для швидкої задачі виконай запит і скажи, що зробив.
Для малої зміни опиши результат у розмові й переходь до звичайного циклу.
Для проєкту підготуй письмовий дизайн і план.
Зупини роботу й підніми масштаб, якщо обсяг зростає під час виконання.
Розділи кілька незалежних проєктів і погодь порядок.
Не починай будувати до погодження повного опису.
Не вважай згоду з ідеєю погодженням опису.
Не використовуй прототип як обхід цього погодження.
Зафіксуй, що саме погоджено.
Не розширюй погоджений обсяг без нового рішення.
Після погодження проєкту переходь до плану.
Повідом, якщо масштаб змінився після початку.
