# Run the chasm diagnostic as a gate

Audit a tech go-to-market with all seven diagnostic questions and rerun the audit as the completion gate before declaring the chasm crossed. Treat each no as a symptom and act on failing rows first; the checks cover a single dominable beachhead, segment references, whole-product gaps, proof-oriented positioning, pragmatist channels, and accelerating adoption.
