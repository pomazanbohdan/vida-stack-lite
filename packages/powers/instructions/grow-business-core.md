# Build a repeatable growth engine

Build a repeatable growth engine in which each phase produces an asset consumed by the next; preserve phase order because skipping Phase 1 removes the shared target. Ask decision questions, record answers, and invoke constituent skills instead of improvising their methods. Fix the offer in Phase 2 before activating outbound, virality, repositioning, or any channel, because traffic to a weak offer is costly.
