# Avoid common chasm-crossing mistakes

Avoid selling to early-majority buyers like early adopters, pursuing multiple beachheads, leaving the whole product incomplete, using revolutionary positioning, or skipping references; instead build the whole product, choose one segment, frame proven value, and invest in references.
