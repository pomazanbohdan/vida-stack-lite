# Set up the interview room

Set up a quiet interview room with a laptop and prototype and a camera recording the screen and customer's face; provide a live video feed to an observation room where the whole team watches and takes whiteboard notes. One Interviewer conducts all five interviews.

# Map the customer journey and expert insights

Map the customer journey by listing customer-type actors and drawing a left-to-right journey in 5-15 steps. Interview teammates with specialized knowledge and capture notes on the whiteboard. Rephrase problems as How Might We opportunities, write one per sticky note, then vote and organize the best on the map.

# Run three-minute lightning demos

Use three-minute demos of competitor and analogous products; presenters say what they found and why it is interesting, and useful ideas are captured on the whiteboard. Borrow ideas from any industry. Divide the map among people if it has multiple parts; otherwise have everyone tackle the same critical problem.

# Record observations in a note grid

Record observations in a grid with one column per customer. Mark each observation positive/success, negative/failure, or neutral/mixed. After all five interviews, count marks by row and look for patterns, including whether all five encountered the same issue.

# Build a realistic facade in one day

Build a realistic facade in one day for Friday testing. Fake the product and prototype only what will be tested; target Goldilocks fidelity because sketches are too low fidelity for honest reactions and working code wastes time. The facade should look real without functioning as a real product.
