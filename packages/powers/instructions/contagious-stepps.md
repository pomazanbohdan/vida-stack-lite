# Use STEPPS as a multiplier, not a checklist

Treat STEPPS as a multiplier, not a checklist: each principle can independently increase sharing, several can be activated together, and one or two done well can substantially increase word of mouth. Use the six questions to assess Social Currency (does sharing improve the sharer’s image?), Triggers (what environmental cue recalls it?), Emotion (does it evoke high-arousal feeling?), Public (can others observe use?), Practical Value (is it useful to pass along?), and Stories (is the brand embedded in a narrative?).
