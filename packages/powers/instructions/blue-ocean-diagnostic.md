# Run the blue-ocean diagnostic

Use all five diagnostic questions to test for a divergent canvas, both elimination and creation, a broken value-cost trade-off, conversion of non-customers, and a buyer-utility leap; apply the paired ERRC, cost, non-customer, or utility action when a check fails.
