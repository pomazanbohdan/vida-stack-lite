# A prototype that disproves the idea is a success
Prototypes are underused, in hobby work and in the enterprise alike.
a prototype is a fast, cheap way to learn, and what it teaches is some of the best input
Current models can produce an impressive first version from one prompt.
Unknowns surface when something runs. They rarely surface in a document.
Finding out that a good-sounding idea is a bad one is a successful prototype.
It saved the cost of building it.
