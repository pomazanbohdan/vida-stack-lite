# Use B=MAP and the Action Line

Behavior occurs when Motivation, Ability, and a Prompt converge at the same moment. A prompt causes behavior only when motivation and ability are sufficient; below the Action Line prompts do not work. High motivation can compensate for low ability and vice versa, but the reliable design strategy is to make behavior easier rather than rely on increased motivation.
