# Stack bonuses against objections

Add bonuses to address remaining objections and specific problems or obstacles to success; assign each an independently justifiable dollar value. Present the most valuable bonus first as the anchor. Name each bonus and favor high-value, low-cost-to-deliver items such as templates, recordings, or access. Partner bonuses can add value at no cost to the seller. The source says that when stacked value exceeds the price, the core product reads as free.
