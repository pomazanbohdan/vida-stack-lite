# Run the STEPPS diagnostic

Use the six Quick Diagnostic questions to assess whether sharing enhances the sharer, an everyday cue recalls the product, it evokes high-arousal emotion, use is visible, it is useful enough to forward, and the brand is embedded in a retellable story. For each no, apply the listed action: add remarkability/exclusivity/achievements; link a frequent context or routine; reframe for awe/excitement/humor/righteous anger; add observable signals or branded outputs; package tips/lists/tools for sharing; or create a brand-dependent Trojan Horse story.
