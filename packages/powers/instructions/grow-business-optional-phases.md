# Add optional phases when their condition appears

Optional skills are added when their listed condition first becomes true: monetizing-innovation if willingness to pay was never tested; good-strategy-bad-strategy if growth efforts scatter without a kernel; traction-eos if execution rhythm cannot keep pace; scorecard-marketing if lead generation needs a quiz/assessment funnel; made-to-stick if referral message is forgettable. Each extends its named docs artifact. Optional phases follow operating rules, load and use each skill like a core phase, and are inserted at the first qualifying point.
