# Оцінюй і застосовуй зауваження перегляду
Прочитай усі зауваження до початку виправлень.
Переформулюй кожне зауваження як технічну вимогу.
Перевір вимогу за кодом, тестами й чинними контрактами.
З'ясуй, чи відтворюється описана проблема.
Перевір вплив запропонованої зміни на наявну поведінку.
Уточни незрозуміле зауваження до будь-якої реалізації.
Розділи блокери, прості виправлення та складні зміни.
Виправ підтверджені блокери перед менш важливими пунктами.
Перевір кожне виправлення окремим цільовим тестом.
Запусти повний потрібний набір після узгоджених виправлень.
Відповідай на кожне зауваження окремо.
Надай доказ, якщо не погоджуєшся з висновком рецензента.
Відхили пропозицію, яка порушує погоджений контракт.
Прибери невикористаний код, якщо зауваження виявило його зайвість.
Не приймай правку лише для демонстрації згоди.
Не виправляй пункт, поки не зрозумів його умову.
Не приховуй зауваження, яке не вдалося перевірити.
Познач залишковий ризик, якщо доказу для оцінки бракує.
Залиш історію змін та результат перевірки пов'язаними.
Заверши оцінку лише після відповіді на всі пункти.
