# Cultivate Type I behavior

Type X behavior is fueled by external rewards, seeks external recognition, and has short-term focus and a fixed mindset. Type I behavior is fueled by autonomy, mastery, and purpose, seeks inherent satisfaction, and has long-term focus and a growth mindset. Design products and teams to cultivate Type I behavior: it is made rather than born, does not disdain money or recognition, is renewable, and promotes well-being. When shifting a team or user base from Type X to Type I, consult references/type-i.md for the behavioral contrast and conversion tactics; consult references/case-studies.md for the named real-world AMP programs.
